MOTREX 구매품의 PoC 데이터 처리 안내

이 안내는 MOTREX 구매실의 견적을 사내 그룹웨어 구매단가품의 임시문서로 작성하는 Chrome 확장 프로그램에 적용됩니다.

어떤 데이터를 사용하나요?

확장은 사용자가 검토한 품의 제목, 품번과 품명, 공급업체, 단가와 거래조건, 선택한 견적 텍스트와 첨부파일을 처리합니다. 문서에 이름이나 연락처가 포함돼 있으면 원문과 함께 처리됩니다. 확장은 이름이나 연락처를 별도 항목으로 수집하지 않으며 비밀번호와 인증 쿠키를 직접 읽지 않습니다.

데이터는 어디로 전달되나요?

사용자가 임시저장을 요청하면 확장은 기존 그룹웨어 로그인 세션에서 품번을 조회합니다. 조회를 통과한 견적 항목과 첨부는 HTTPS를 통해 MOTREX 사내 그룹웨어의 임시문서에 저장됩니다. 품번 검증과 임시저장을 위해 필요한 범위에서만 데이터를 사용합니다. 확장에는 광고, 사용자 분석 수집, 데이터 판매 기능이 없습니다.

확장과 연결된 구매실 웹 서비스는 사용자가 제출한 견적 텍스트와 파일을 분석합니다. AI 추출을 요청하면 문서에서 읽은 텍스트를 모트렉스 사내 AI 서비스로 전달합니다. 구매실의 견적 추출 기능은 원본 파일을 보관함에 등록하지 않습니다.

언제 삭제되나요?

확장은 실행 중 입력값과 첨부를 브라우저 세션에 임시 보관합니다. 작업이 끝나면 작업 데이터를 지우며, 중복 실행 방지에 필요한 작업 ID, 처리 시각, 상태, 탭 식별자는 현재 브라우저 세션 동안 남습니다. 구매실 서버는 검토를 확정한 회사 계정, 작업 ID, 검토 시각, 품목 수를 업무 이력으로 기록합니다. 저장된 임시문서와 업무 이력에는 모트렉스의 사내 보관 및 접근 기준이 적용됩니다.

문서 정정, 삭제 및 문의

작성자는 그룹웨어 임시함의 권한 범위에서 임시문서를 확인하고 수정하거나 삭제할 수 있습니다. 데이터 처리와 업무 이력에 관한 문의는 사내 AI Task 운영 담당자에게 전달해 주세요. 보안 문제는 모트렉스의 공식 정보보호 신고센터에 접수할 수 있습니다. 모트렉스 정보보호 및 개인정보 안내

English summary

The MOTREX Purchase Approval PoC extension processes quote fields and attachments that authorized users select and review. The extension uses the user’s existing sign-in session to verify the item code and save a draft in the MOTREX groupware over HTTPS.

Job data is held temporarily in browser session storage. A job identifier, status, timestamp and tab identifier can remain for the session to prevent duplicate runs. The connected Purchasing portal sends extracted text to MOTREX’s internal AI service when the user requests AI extraction. It records the company account, job identifier, review time and item count in the internal audit trail. Personal details embedded in a selected document can travel with that document.

The extension uses the data only to carry out the requested workflow. It does not sell it, use it for advertising or analytics, or read passwords or authentication cookies directly. It uses data in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.
